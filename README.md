# HRM Watcher

Your BUE HRM attendance, leaves and balance, checked against the attendance policy. Everything
stays on your phone; the app only reads HRM, and sends a request only when you hold the button.

## Android
Download and install: **[hrm-watcher.apk](https://github.com/liolah/hrm-watcher-releases/releases/latest/download/hrm-watcher.apk)** (version 1.0.0).
Android asks once to allow installs from your browser. Later versions arrive by themselves.

## iPhone (free, in Expo Go)
1. Install **Expo Go** from the App Store.
2. Scan this code with the iPhone camera. No Expo account is needed.

![iPhone QR code](hrm-watcher-iphone-qr.svg)

Or open this link on the iPhone: `exp://u.expo.dev/608ec8a1-c527-4ff3-91e0-cc1d75e76d43?runtime-version=exposdk%3A54.0.0&channel-name=preview`

Next time, open it from Expo Go under **Recently opened**. New versions arrive by themselves.

## First steps
Settings → HRM account: your HRM username and password. They stay in the phone's secure storage.
